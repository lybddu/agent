### 3. 用户画像（User Profile / 用户记忆）

- **含义**：与**单个用户**绑定的属性、偏好、历史行为摘要。
- **典型内容**： demographic 信息（若合规使用）、偏好设置（语言、长度、风格）、禁忌与约束（不吃辣、不提某竞品）、历史交互的统计或摘要（常问哪类问题、常用哪些功能）。

### 4. 任务态势（Task / Session State）

- **含义**：与**某一次任务或会话**绑定的进度、中间结果、待办。



# 二、 mem0 记忆功能

mem0 是面向 AI Agent 的**通用记忆层**：支持按 user_id / agent_id / run_id 组织记忆、用 LLM 从对话中**推断**结构化记忆、向量检索与更新/删除，适合“长期、跨会话、可检索”的个性化记忆。
本节的示例基于 **mem0 开源 Python SDK**（`pip install mem0ai`），需配置 `OPENAI_API_KEY`（用于推理与向量嵌入）。
